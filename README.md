### 👋 Hi, I'm Daniel

I make sure software and data can be trusted. I'm a **Data Quality Analyst at Stellantis Financial Services US**, where I validate the SQL
transformations and ETL pipelines behind financial reporting. On my own time I build **test systems that find real bugs**.

- 🧪 **Now:** automating API, web, mobile, contract, security and performance testing end to end
- 🗄️ **Daily:** T-SQL, PostgreSQL, data reconciliation, root-causing data defects
- 🎓 BSc Computer Science (Kirinyaga University) · ALX Software Engineering (Backend)
- 💼 **Open to** QA / test automation and data quality roles (remote, with 4+ hours of US overlap)
